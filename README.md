# ISRLATA website starter

A responsive static website for **ISRLATA — Integrated and Sustainable Real Life African Transformation Action**.

## Files
- `index.html` — main website
- `styles.css` — layout, colours and mobile styling
- `script.js` — mobile navigation and current-year footer
- `privacy-policy.html` — initial policy template; review before launch

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com/signup.
2. Create a **public** repository named `isrlata-website`.
3. Upload all four website files to the repository root (you can also upload this README).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The URL appears in Settings → Pages.

Official guide: https://docs.github.com/en/pages/quickstart
